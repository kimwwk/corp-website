§01 · The contract

Twelve rules. Every page follows all of them.

Consistency beats novelty. A page is composed only from the chrome in §05 and the patterns in §06 — nothing else. If a page needs a new pattern, it gets added to this file first, reviewed, and only then built.

  1. Chrome is identical everywhere. The nav and footer in §05, exactly — same links, same order, same CTA label ("Free Fit Check"), same hover rules. No page-specific variants.
  2. Every page opens with P1 or P2. Home opens with the green hero band (P1). Every other page opens with the cream page header (P2).
  3. Offer pages end on green. Home, About, Audit, Services close with P12. Utility pages (Contact, Book, Fit Check, Showcase) end quietly on cream — no band.
  4. Green bands per page: Home max three (hero, featured, close). Interior pages max two. Never two bands adjacent.
  5. One depth ring per band, at a fixed position: hero → right/bottom, featured → right/top, close → left/top. Nothing else decorates a band.
  6. Section rhythm: standard padding clamp(4rem, 9vw, 7rem), quiet sections clamp(3rem, 7vw, 5rem). Consecutive cream sections are separated by a hairline top rule. Never a hairline touching a band.
  7. Any list of three or more items is hairline rows — P4 (facts) or P5 (benefits/symptoms). No floating bullets, no icon tiles, no card grids for content.
  8. Numbers appear only as P7 big numerals. No "01/02" mono chips, no numbered circles, no counters in any other style.
  9. One primary pill per section, max. Optionally one underlined text link beside it (link-green on cream, link-leaf on green). Pills are always fully rounded. The same action keeps the same label on every page.
  10. Markers are scarce. Max one marker underline per heading; max two interludes on Home, at most one on any interior page. Markers never appear in body text.
  11. White cards are reserved for the price panel, forms, and product tiles. Editorial content never sits in a card.
  12. Color discipline: leaf and leaf-tint exist only on green surfaces; deep green is the only accent on cream. Body text on green bands is cream — never a grey tint.

§08 · Motion

Four movements. Nothing else moves.

  1. Reveal: sections fade-rise 18px over 0.6s ease, once, at 12% visibility. Sibling rows may stagger 40ms.
  2. Marker draw: the underline draws left-to-right over 0.9s, starting 0.35s after its section reveals. Stroke sits behind the glyphs.
  3. Hovers: button background/color 0.18s; ladder arrow slides in 0.25s; row background cream→white 0.2s.
  4. Reduced motion: everything above becomes static and instant. Markers render drawn. No exceptions.

§09 · Do / Don’t

The fast checklist.

Do
  • Compose every page from P1–P13 and the §05 chrome.
  • Put every 3+ item list in hairline rows.
  • End offer pages on one green band with the CTAs inside it.
  • Use mono uppercase for every label, price, and support line.
  • Keep one primary pill per section, same label site-wide.
  • Add a new pattern to this file first, then build it.
Don’t
  • Invent a per-page H1 size, list style, or numbering format.
  • Use icon tiles, content cards, gradients, or shadows (price card excepted).
  • Put leaf/leaf-tint on cream, or grey text on green.
  • Stack two green bands, or hairline against a band.
  • Use more than one marker per heading or two interludes per page.
  • Give one action two different button labels.
